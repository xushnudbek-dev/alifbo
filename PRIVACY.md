# Privacy Policy — Alifbo Konvertori

Last updated: November 6, 2026

## What this app collects

**Alifbo Konvertori collects no data.**

- It does **not** collect, store, or transmit any personal information.
- It does **not** use analytics, advertising, or telemetry services.
- Text you convert is processed **entirely on your device** and never leaves the app.
- It does not read your files, contacts, location, or browsing activity.

## Keyboard layout

The Windows keyboard layout component only translates keystrokes (sh→ş, ch→ç, oʻ→ö, gʻ→ğ) locally. It sends nothing over the network.

## Permissions

The app uses only minor local system features (working with text and the optional startup shortcut). No internet permission beyond WebView loading local UI content.

## App settings

App preferences (startup on/off) are stored only in your local Windows profile settings and can be removed by uninstalling the app.
